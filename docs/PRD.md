# 사이트 설계도(PRD) — 과학드론 교구 사이트 (가칭)

작성일: 2026-10-10 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
초·중·고 과학드론 교구를 소개하고, 학교와 방과후 수업에 도입하려는 분들의 문의를 받는 사이트.

## 2. 손님
- 누가: 학교 선생님, 방과후 강사
- 어디서 알고 오나: 검색(네이버·구글), 교사 연수·교육 박람회, 블로그·유튜브·인스타

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 가격 (1대 가격, 학급 세트 가격)
2. 수업 자료 (수업 계획서·활동지가 함께 오는지)
3. 구매 방법 (학교 예산으로 살 수 있는지, 견적서 발급)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 교구 사진, 시연 영상
- 인증·자격: (미정 — 정확한 인증 이름을 받아서 넣는다)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 도입 문의하기
- 누르면: 문의 폼 (폼 안에서 견적 요청 / 도입 상담 / 시연·샘플 신청 중 고름)

## 6. 페이지 구성 (위에서 아래로)
1. 첫 화면 — 한 문장 + "도입 문의하기" 버튼
2. 교구 소개 — 사진, 시연 영상
3. 궁금한 것 세 가지 — 가격 · 수업 자료 · 구매 방법
4. 인증·자격
5. 후기 자리 (비워 둠)
6. 문의 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 소속 (학교·기관 이름)
- 문의 종류: 견적 요청 / 도입 상담 / 시연·샘플 신청
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 회사 이름: (미정)
- 제품 이름: (미정)
- 가격: (미정)
- 전화: (미정)
- 이메일: (미정)
- 위치: (미정 — 필요할 때만)

## 9. 이번에 넣지 않을 것
- 수업 자료 내려받기
- 온라인 결제·장바구니 (기본으로 다음에 — 꼭 넣고 싶으면 다시 정한다)
- 회원가입·로그인 (기본으로 다음에)
- 블로그·공지사항 게시판 (기본으로 다음에)

## 10. 첫 화면 한 문장 후보
1. 교실에서 바로 쓰는 초·중·고 과학드론 교구
2. 선생님과 방과후 강사를 위한 과학드론 교구, 견적부터 시연까지 문의하세요
3. 과학드론 수업, 가격·수업 자료·구매 방법을 한 번에 물어보세요

## 11. 다음에 할 것
- 8번 사실(회사·제품·가격·전화·이메일) 채우기
- 인증 이름 확인해서 4번에 넣기
- 실제 후기 모이면 후기 자리 채우기
- 수업 자료 내려받기, 결제, 회원가입, 게시판

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 어두운 밤하늘 남보라 + 드론 비행 궤적 빛 · 참고 디자인: 사용자가 준 어두운 보라 빛 캡처(그대로 베끼지 않고 분위기만)
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel
- 유입 추적: UTM 꼬리표(30일 기억) + 들어온 사이트 도메인을 문의와 함께 저장, /admin에서 경로별 문의 수와 추적 링크 만들기

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. (문의 저장이 '예'일 때) 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
